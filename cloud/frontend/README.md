# RESPIRA AI — Cloud Frontend

## Future Responsibility

The `cloud/frontend` directory will house the React + TypeScript single-page application for central System Administrators.

### Expected Future Features:
- **System Admin Login**: Secure authentication for platform operations personnel.
- **Hospital Registry Dashboard**: Overview of all onboarding and active partner hospitals.
- **Hospital Onboarding Interface**: Management screens to register new hospital nodes and issue connection tokens.
- **Hospital Node Monitoring**: Live status dashboard displaying online/offline status, IP metadata, software versions, and last heartbeat timestamps.
- **Federated Learning Monitoring**: Real-time visual tracking of FL training rounds, participating nodes, convergence metrics, and global model updates.
- **Global Model Version Control**: Administration interface to inspect, test, approve, and publish new global model releases.
- **Federation Rounds Overview**: Historical logs and status reports of all completed and active FL training sessions.
- **Cloud Audit Logs**: Security log viewer for central system events, access logs, and node registration activity.

> [!NOTE]
> This interface is intended solely for central administrative and federation oversight. It does not provide access to individual patient records or clinical imaging data.
